A dashed box saying a list or view is empty, with an optional way forward.
Props: `title`, `body`, `action`, `icon`, `level` (the title's heading level,
2 to 4, which never changes its look) and `art`, a slot above the icon for a
surface's own illustration. Each surface writes its own title and body; none
shares another's words.
