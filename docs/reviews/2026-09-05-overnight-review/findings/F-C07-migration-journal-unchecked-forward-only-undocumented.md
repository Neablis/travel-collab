# F-C07 — Migration journal consistency is checked nowhere in CI, and "forward-only" is written down nowhere

- **Stream:** C Versioning + D Infra (D03's deterministic half) · **Severity:** LOW · **Confidence:** CONFIRMED (verified, with one correction)
- **Area:** `apps/web/drizzle/meta/_journal.json` (idx 0–15, `when` strictly increasing today); `.github/workflows/ci.yml` and every `package.json` — no `drizzle-kit check` (only `db:generate`/`db:migrate`, `apps/web/package.json:19-20`); irreversible data steps at `drizzle/0002_*.sql:3` (UPDATE backfill) and `0005_*.sql:7-13` (`DELETE FROM pages`); `docs/guidelines/environments-and-deploys.md` and ADR-004 contain no rollback / forward-only statement.
- **What is wrong:** `drizzle-kit check` passes today (run this session with a dummy `DATABASE_URL`, ~2s) but nothing keeps it so. Two agents generating in parallel both produce `0016_*` with `idx: 16`; git usually conflicts on `_journal.json`, but a bad resolution that keeps both entries is caught only when `drizzle-kit migrate` runs. Drizzle's migrator applies only entries whose `created_at` is newer than the last applied row (see F-D03), so a non-monotonic journal silently skips a migration. No migration has a down script; rollback is "a new forward migration", which is fine if written down. Correction to the first draft: CI's int lane *does* execute every migration into an empty database (`with-test-db.mjs:202`), so the SQL is exercised — only schema drift and journal shape are unchecked.
- **Suggested fix:** `scripts/check-migration-journal.mjs` appended to root `lint` (`package.json:12`): idx contiguous, `when` strictly increasing, exactly one `.sql` per entry, snapshot count matches; plus `pnpm --filter web exec drizzle-kit check` in the CI unit job with a placeholder `DATABASE_URL`; one sentence in `environments-and-deploys.md` that migrations are forward-only.
- **Scope of the fix:** one script + `scripts/__tests__/check-migration-journal.test.mjs` (with a swapped-`when` fixture that goes red), `package.json`, `ci.yml`, one guideline line. Check subset: `node --test scripts/__tests__`, `pnpm lint`.
- **Cross-reference:** ADR-004, F-D03, F-C03.
