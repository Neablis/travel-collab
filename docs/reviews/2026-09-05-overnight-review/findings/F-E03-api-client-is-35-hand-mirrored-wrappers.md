# F-E03 — The "typed API client" is 35 hand-mirrored fetch wrappers plus a second client plus three raw fetches; the MSW mocks are hand-written, not "generated from contracts"

- **Stream:** E Maintainability · **Severity:** MEDIUM · **Confidence:** CONFIRMED (verified; one sub-claim corrected)
- **Area:** `apps/web/src/lib/apiClient.ts` (999 lines, 35 `fetch(` calls against 37 `route.ts` files, 35 byte-identical `} catch (err) {` blocks returning `{ ok: false, error: { status: 0, ... } }`); `apps/web/src/lib/pagesClient.ts` (a second client with its own `networkError`/`refusal` helpers and its own mirrored totality suite `pagesClient.test.ts:71-115`); raw `fetch` outside both clients at `app/(app)/page.tsx:109`, `components/board/LocationInput.tsx:27`, `app/sentry-example-page/page.tsx:81`; `apps/web/src/mocks/handlers.ts:15-16` ("Deliberately naive state transitions", 12 hand-written handlers); `AGENTS.md:116,191-192` and `docs/guidelines/connecting-the-parts.md:7,53` promise "the typed API client" and "MSW mocks generated from contracts".
- **What is wrong:** every new route costs a hand-written wrapper, a hand-written mock and a hand-copied try/catch, and the totality invariant ("a client helper never rejects") is guarded per module: `apiClient.test.ts:229-261` enumerates that module's exports — it cannot see `pagesClient.ts` (which had to grow its own copy of the suite after a reject bug in 2026-09-03, recorded in its header) or any raw `fetch`. Nothing lints `fetch` outside the client. Two guideline sentences describe generation that does not exist.
- **Suggested fix:** (1) A `fetch`-outside-client lint first — `no-restricted-syntax` on `CallExpression[callee.name='fetch']` for everything under `apps/web/src` except `lib/apiClient.ts`/`lib/pagesClient.ts` — that is 80% of the value at 2% of the cost. (2) Collapse both clients onto one `request<T>(path, init, parse): Promise<ApiResult<T>>` core so totality is structural (one try/catch, not 35) and fold `pagesClient` into it. (3) Fix the two docs to say "hand-written against the contract schemas", or build the small route table `{ path, method, input?, output }` from which client, MSW handler and route body parse all derive — decide which, do not leave the claim standing.
- **Scope of the fix:** `apps/web/eslint.config.mjs`, `lib/apiClient.ts`, `lib/pagesClient.ts`, `page.tsx`, `LocationInput.tsx`, `mocks/handlers.ts`, `AGENTS.md`, `connecting-the-parts.md`. No contracts. Check subset: web unit lane + `pnpm lint`.
- **Test that should exist:** the lint (prove it by adding a raw `fetch` in a component and watching `pnpm lint` go red); the totality suite then covers the single core.
