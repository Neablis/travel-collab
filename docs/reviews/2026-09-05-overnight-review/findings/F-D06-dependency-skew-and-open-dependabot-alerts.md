# F-D06 — Dependency hygiene: drizzle-kit is ~18 months behind the ORM it generates for, `next-auth` floats on a beta, and GitHub reports 17 open Dependabot vulnerabilities (9 high) on `main`

- **Stream:** D Infra · **Severity:** LOW-MEDIUM (the Dependabot count is the part that needs a human look) · **Confidence:** CONFIRMED facts; skew impact downgraded to LOW (verified)
- **Area:** `apps/web/package.json` + `pnpm-lock.yaml:3443` (`drizzle-kit@0.28.1`), `:3447` (`drizzle-orm@0.45.2`; registry latest kit is 0.31.10), `:4599` (`next-auth@5.0.0-beta.32` under `^5.0.0-beta.32`), `:386` (`@auth/core@0.41.3`, whose internals ADR-034:31-38 verified by reading), `:3645` (`eslint-config-next@15.5.20` under `next@16.3.3`), `@types/node@22` (Vercel builds on 24 — `docs/known-issues/open/KI-20260902-node-26-breaks-the-local-unit-lane-while-ci-stays-green.md:22`); `.github/dependabot.yml:34-41` (monthly, grouped, majors ignored). The push output on 2026-09-05 00:40 PT: "GitHub found 17 vulnerabilities on Neablis/travel-collab's default branch (9 high, 8 moderate)" — https://github.com/Neablis/travel-collab/security/dependabot.
- **What is wrong:** (1) The lockfile pins everything and CI/Vercel install frozen, so `^` ranges float only via Dependabot — but Dependabot ignores majors, and a 0.x package's `^0.28.0` pins to 0.28.x, so `drizzle-kit` never moves. The *apply* path is current code (drizzle-kit delegates `migrate` to the installed ORM), so only `db:generate`'s diff engine is old; failure mode is a wrong or empty diff, not a crash. (2) `next-auth` beta.33+ does not exist yet, but when it does the group bump will carry it past internals an ADR depends on. (3) 17 open alerts with 9 high is unassessed — most are probably dev-only transitive, but nothing in the repo records a triage.
- **Suggested fix:** triage the Dependabot alerts (a human with GitHub access; record the outcome in a KI or `SECURITY.md`); bump `drizzle-kit` to `^0.31` alone and prove it with `pnpm --filter web db:generate` printing no schema change; pin `next-auth` exactly and run `node scripts/check-auth-proxy.mjs` as the ADR-034 regression on any bump; bump `eslint-config-next` with the next `next` minor.
- **Scope of the fix:** `apps/web/package.json`, lockfile, possibly `.github/dependabot.yml`. Check subset: `pnpm --filter web db:generate` (no diff), `pnpm check` after a kit bump.
- **Cross-reference:** ADR-034, KI-20260902 (Node versions), F-D05.
- **Do not:** let Dependabot's monthly group carry the drizzle-kit jump — it is a tooling migration, do it alone.
