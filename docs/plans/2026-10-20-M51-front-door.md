# M51 plan — the front door tells the story

Milestone: `docs/milestones/M51-the-front-door-tells-the-story.md` (the decisions are there; this
file is the build plan). The C2 prototype the build follows is
https://claude.ai/artifact/Fvkoyjzu6mqxS9KxHZaGhK.

Paths are under `apps/web/` unless they start with `packages/`, `content/`, `docs/` or `scripts/`.
`:N` is a line at `1715c45`; re-read before relying on one.

Every part targets `main` on a branch `claude/m51-part<K>-<slug>` and merges on its own. A part
that needs an earlier one waits for it to merge, then branches from `main`. No migration is
planned; if one turns out to be needed, it takes the next free number after rebasing on `main`.
This file is deleted at gate close (git history keeps it).

after part 2 merges, adds `addedBy` to the snapshot and asserts the names in the crew cell. Either
way, the later of the two to merge owns that wiring.
