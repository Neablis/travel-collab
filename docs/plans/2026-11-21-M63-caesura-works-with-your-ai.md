every part.

### Facts the parts share (the survey, 2026-11-21)

- **No development details** (D2, D11) on `/ai`, `/security` or `/agents.md`. Never mention the
  repository, `AGENTS.md`, how Caesura is built, response header names, hosting or database vendors, or
  libraries. A unit test on each page's rendered text guards this with a deny-list of words, for
  example `github`, `AGENTS.md`, `Neon`, `Hetzner`, `Coolify`, `Strict-Transport-Security`,
  `Content-Security-Policy`, `Next.js` and `Scalar`.
- **Static pages:** `/developers` is the precedent. It is `src/app/(front)/developers/page.tsx` with
  `pageMetadata` (`src/lib/siteMetadata.ts`), rendering `src/components/front/DevelopersScreen.tsx`.
  New pages go outside `src/proxy.ts`'s matcher (`:309`).
- **OG images:** only the root `src/app/opengraph-image.png` exists. Each new page adds its own
  `opengraph-image` beside its `page.tsx`, using the root image's convention and an `.alt.txt` file.
- **JSON-LD:** `src/lib/jsonLd.ts` (Organization `:37`, WebSite `:42`, Breadcrumb `:111`) and
  `src/components/JsonLd.tsx`. There is no `WebPage`, `FAQPage` or `SoftwareApplication` helper yet;
  part 4 adds them.
- **Length limits (M53):** titles of 60 characters or fewer and descriptions of 160 or fewer. No general
  test exists, so each page's metadata test asserts both.
- **Scopes:** `SCOPE_CATALOGUE` is in `packages/contracts/src/publicApi.ts:104`. MCP tools in
  `src/app/api/mcp/tools.ts` declare no scope of their own. Each one names a v1 `handler`, whose
  `DECLARED` symbol (`src/server/public-api/route.ts:358`, `:469`) carries the scope. The MCP tool
  table is therefore derived by joining a tool to its handler's declaration, not typed by hand.
- **OpenAPI:** built by `buildOpenApi` (`src/server/public-api/openapi.ts:347`) from every `v1/**/route.ts`.
  The output is the committed `src/app/api/v1/openapi.json`, regenerated by `pnpm --filter web
  openapi:generate`. Scalar is `@scalar/api-reference-react@0.9.90`, which uses
  `@scalar/api-reference@1.78.1`.
- **Discovery:** `src/app/llms.txt/route.ts`, `src/app/.well-known/api-catalog/route.ts:22`,
  `src/app/.well-known/poppy.json/route.ts` and `src/app/.well-known/security.txt/route.ts` (EMAIL `:28`,
  EXPIRES `:31`, no `Policy:` line). They are tested together in `src/server/public-api/discovery.test.ts`.
- **Security facts for `/security`:** M62 is on `main`. The Security tab is in
  `src/components/account/AccountScreen.tsx` (`:51`), with TwoStepSection, TokensSection and
  ConnectedAppsSection. `security_epoch` is in `src/server/mfa/state.ts`. HSTS and CSP are in
  `apps/web/next.config.ts` (`:120`–`:138`); the page states what they achieve, never their names.

second factor (passkeys, authenticator apps, recovery codes; M62 is on `main`); what an AI tool or a
token can do (one line, then links to `/ai` and `/developers#scopes`); taking access back (tokens,
