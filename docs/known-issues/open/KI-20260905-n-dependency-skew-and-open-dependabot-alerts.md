### KI-2026-09-05-n — 17 open Dependabot alerts (9 high) on `main` are untriaged, and three dependencies are skewed against what they build for

- **Severity:** correctness risk (the alert count is unassessed, so its severity is genuinely unknown — that is the finding)
- **Area:** `apps/web/package.json` + `pnpm-lock.yaml:3443` (`drizzle-kit@0.28.1`), `:3447` (`drizzle-orm@0.45.2`; registry latest kit is 0.31.10), `:4599` (`next-auth@5.0.0-beta.32` under `^5.0.0-beta.32`), `:386` (`@auth/core@0.41.3`, whose internals ADR-034:31-38 verified by *reading*), `:3645` (`eslint-config-next@15.5.20` under `next@16.3.3`), `@types/node@22` against a Vercel build on 24; `.github/dependabot.yml:34-41` (monthly, grouped, **majors ignored**)
- **Symptom / What happens:** the push on 2026-09-05 00:40 PT reported "GitHub found 17 vulnerabilities" (9 high) on `main`. Nothing in the repo records a triage of them; most are probably dev-only transitives, but "probably" is the whole problem. Separately: the lockfile pins everything and CI/Vercel install frozen, so `^` ranges float only via Dependabot — which ignores majors, and a 0.x package's `^0.28.0` pins to 0.28.x, so **`drizzle-kit` never moves**. Its *apply* path is current code (it delegates `migrate` to the installed ORM), so only `db:generate`'s diff engine is ~18 months old; the failure mode is a wrong or empty diff, not a crash — which is why the skew half is LOW. `next-auth` beta.33+ does not exist yet, but when it does a grouped bump will carry it past internals an ADR depends on.
- **Why not fixed here:** the triage needs a human with GitHub Security access — the alerts are not readable from the repo. Found by a read-only review; no code was changed by it.
- **Suggested fix:** triage the alerts and **record the outcome in this entry or in `SECURITY.md`**, so the count stops being invisible; bump `drizzle-kit` to `^0.31` alone and prove it with `pnpm --filter web db:generate` printing no schema change; pin `next-auth` exactly and run `node scripts/check-auth-proxy.mjs` as the ADR-034 regression on any bump; bump `eslint-config-next` with the next `next` minor.
