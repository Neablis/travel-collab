### KI-2026-09-11-c — two `modelSelection` tests assert the compiled model default and go red under any ambient `AI_MODEL_*`

- **Severity:** correctness of the test lane (non-hermetic tests; they fail on a developer machine that has the production models configured, which is the machine most likely to have them)
- **Area:** `apps/web/src/server/ai/modelSelection.test.ts` — the cases *"returns a model for every tier…"* and *"reports the resolved tier map…"*; `apps/web/src/server/config.ts` (`serverConfig`, read at module load)
- **Symptom:** both cases assert the **compiled** default (`DEFAULT_AI_MODEL`, `anthropic/claude-haiku-4-5`). `serverConfig` is read at module load, so a `vi.stubEnv` inside the test is too late — an ambient `AI_MODEL`, `AI_MODEL_CHEAP`, `AI_MODEL_MID` or `AI_MODEL_STRONG` in the shell makes them fail. They pass today only because nobody running them has those set.
- **Not the same as the one fixed beside it.** PR #162's review fixed a third case in the same file that *could* be stubbed (`AI_MODEL_MID` cleared before an isolated import). These two cannot: they read `serverConfig` at module load, so each needs the isolated-import treatment (`vi.resetModules()` + `await import(...)`) that the tier-map test already uses. **CodeRabbit's stated mechanism for the third case was wrong in a way worth repeating here** — it reported the test would silently *skip* the fallback path; measured, it goes **red**. The defect in all three is non-hermeticity, not a vacuous pass.
- **Why it matters more than a flaky test:** production runs `deepseek/deepseek-v4-flash-0731` while `config.ts:15` compiles `anthropic/claude-haiku-4-5` (M20 link 5 records that gap already costing one estimate an order of magnitude). A developer who sets `AI_MODEL` locally to reproduce production is exactly the person these tests will fail for, and the failure will look like their change.
- **Fix path:** give both cases the isolated-import treatment already used in the same file, so they resolve `serverConfig` after the stubs rather than before. Consider whether `serverConfig`'s module-load read is the real defect — `envCeiling` in `quota.ts` deliberately reads at **call** time, and the two mechanisms disagree (recorded in `docs/specs/2026-09-10-assistant-kernel-design.md` §6b correction 7, where it also pre-decides an open question about whether the tier map should be a flag).
- **Found by:** M9 Phase 0, PR #162 review round, while proving CodeRabbit's finding E. Not fixed there because it is two more cases in a file the review touched for one, and the fix is a different mechanism.
- **Cross-reference:** ADR-043 (M9 Phase 0), ADR-019, M20 link 5.
- **First noted:** 2026-09-11.
